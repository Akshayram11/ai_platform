LLM gateway keys

One active key per app lives in the app's secret as DAPP_LLM_KEY and is created by dapp deploy when the app has llm: true. The gateway keeps only a hash, so a key can't be shown again. Rotate = new key stored, DataOS restarts the app (~40s), old key revoked afterwards, no failed calls. Revoke = kill a key right now; an app still using it gets errors until you rotate.
