Stay signed in to Claude

DataOS replaces pods now and then, and every deploy does too. Without a token you sign in to Claude in the terminal again each time. With one you never do. Get it once on your own computer (you need a Claude subscription):

claude setup-token     # prints a token valid for a year

Kept as the DataOS secret dapp-{{ mine.app }}-anthropic, readable only by your instance, never shown again. {% if mine.exists %}Saving restarts your Claude Code to use it.{% endif %} Don't paste it anywhere else (chats, tickets).
