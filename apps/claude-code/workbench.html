Claude Code on DataOS desktop off Preview:
Claude is using the screen

The desktop is off.

It starts when you press Start desktop, or by itself when Claude needs it (ask it to "open a page" or "look at the screen"). You and Claude share this one screen: a browser, and a right-click menu for a terminal and a file manager. Sign in to a site here yourself, and Claude can work in that session without seeing your password.

To save resources it stops after 15 minutes with nobody using it. Its sign-ins are kept on this machine's disk.
